# 数据与恢复约定

## 本地保存优先

Watch 音频回调先向 CAF 文件写入 PCM，再尝试转换出 16 kHz、mono、Int16 小端实时数据。
本地文件使用原始采样率、原始声道数、16 位 PCM，避免实时网络或重采样失败导致录音丢失。
CAF 适合保留被中断录音的可读帧，但崩溃恢复仍须真机验证，不能承诺恢复全部帧。
48 kHz 单声道约占 346 MB/小时；磁盘写入失败会停止录音并保留已有文件。
当前没有自动清理或压缩。长录音前应确认容量。

开始前写入 manifest；停止引擎、移除 tap、关闭文件后，才标记 finalized 并排队传输。
重新启动会尝试读取尚未 finalized 的文件，恢复其可读时长，不能读取的文件保留且显示错误。
系统中断时保存现有音频，不自动重新开始录音，以免用户误以为录音从未中断。

## 文件同步与确认

`transferFile` 不要求 `isReachable`，只要求 WCSession 已激活。Watch 只为不在系统传输队列中的
未确认 ID 排队。失败、重新激活及用户重试时重新扫描；不无限立即重试。
手机必须在 WCSession delegate 返回前复制临时 URL，再在主 actor 中验证可读音频并写入索引。
索引持久化成功后通过 `transferUserInfo` 回传 ID 确认；传输完成回调不等于手机持久化成功。
Watch 收到确认后仍保留音频，允许用户手动删除副本。
手机按 UUID 去重，并保留删除 tombstone，防止延迟重传导致录音复活。
尚无索引记录的同名音频视为上次导入的孤立文件，以已验证的重传文件原子替换，防止复用半文件。
手机删除不会自动删除手表副本。这一行为在双端 UI 中告知用户。
索引解析失败时停止覆盖该索引，保留文件，显示恢复错误。

## 录后转写

手机单任务队列串行转写；实时任务开始时取消录后任务并保留已完成段进度。
每段最多 40 秒，按时间范围导出临时 M4A，成功或失败都会清理该临时段。
每完成一段便持久化结果，重试跳过已完成段。最终全文成功后覆盖临时字幕。
任务取消、超时、错误均结束对应识别任务；原音频不删除。
App 重启后正在执行的任务显示为中断，可显式重试。失败不会被描述为已完成。
分段边界可能截断词语；目前无重叠和词级去重。无声段可能被 Speech 判为失败，允许重试但
不静默跳过该段，以免把未知识别失败伪装成无声。5/30/60 分钟准确率与完整性仍须实录验收。

## 实时链路

只有用户已在 iPhone 确认识别方式并授权，且两端可达时才启用。
每个包携带 recording ID 和单调序号，序号缺口或旧会话包被拒绝；ack 后才能发送下一包。
PCM 每秒一包，超时／拥塞后降级为本地录音，UI 可手动重连；可达性恢复自动发起新识别窗口。
每次重连分配新的 stream ID；旧连接的音频、字幕、错误和停止消息不能影响新连接。
手机每约 45 秒轮换 Speech 请求，以最后 2,000 字作为临时字幕窗口，8 秒无音频则释放识别器。
窗口轮换及断连可能丢失实时文字，字幕不是完整笔记；完整音频的录后转写才是最终全文。
切换到实时模式时同步取消旧录后识别请求，再启动新的请求，避免两个识别请求重叠。
后台、锁屏和远离手机的实时链路没有持续可用保证。不使用 watchOS Speech 识别。

## 隐私

默认 `requiresOnDeviceRecognition = true`，没有本地中文模型则报错。
用户明确打开“允许 Apple 在线识别”后才允许系统在线处理。切换该选项会取消已有识别任务。
应用没有第三方密钥、遥测上传、自建服务器。在线 Speech 的数据处理受 Apple 的服务规则约束。
生产发布前仍须完成正式隐私政策 URL、App Store 隐私标签和实际数据流审查。

## 写盘失败

双端索引通过 `DurableJSON` 保存。候选索引只有成功写盘后才发布到内存/UI；磁盘空间不足不会
把尚未保存的编辑、分段进度或接收确认显示为已保存。损坏的旧索引不会被默认空索引覆盖。
转写检查点保存失败会结束该次转写，保留上一次持久化进度和原始音频，可在释放空间后重试。

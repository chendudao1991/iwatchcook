# MVP 验收清单

> 初始状态：待在 macOS/Xcode 中构建与真机验证。不要将未运行的检查标记为通过。

## A. 工程与权限
- [ ] XcodeGen 成功生成 iOS + watchOS 工程。
- [ ] iOS 和 watchOS 两个 target 均能编译。
- [ ] 两个 target 的 Bundle ID、Watch App 嵌入、签名和配对配置正确。
- [ ] 首次使用正确请求麦克风权限。
- [ ] iPhone 端正确请求语音识别权限。

## B. Apple Watch 录音
- [ ] 录音开始后时长持续更新。
- [ ] 结束录音后文件完整关闭且存在。
- [ ] 手机不连接时仍可录音并保存。
- [ ] 5 分钟、30 分钟、60 分钟录音通过真机测试。
- [ ] 熄屏、抬腕、切换 App、低电量与来电场景已测试。

## C. 文件同步
- [ ] `transferFile` 成功传输并在 iPhone 端落盘。
- [ ] 重复收到相同 ID 不会生成重复记录。
- [ ] 手机暂不可达时，文件保留在传输队列。
- [ ] 同步后 iPhone 可播放完整音频。

## D. 录后转写
- [ ] 普通话音频可以转写。
- [ ] 5 分钟、30 分钟、60 分钟音频分别测试。
- [ ] 分段结果顺序正确，无明显段落遗漏。
- [ ] 权限拒绝、无可用识别器、网络/识别失败时显示清晰状态。
- [ ] 失败后可重试，原始音频不丢失。
- [ ] 编辑后的文字可保存，退出重开后仍存在。

## E. 实时字幕
- [ ] 手机前台、手表与手机可达时可收到字幕。
- [ ] 临时字幕能更新，结束后完整转写覆盖临时字幕。
- [ ] 手机离开、锁屏、弱网和短暂断连时显示正确状态。
- [ ] 实时分片失败不影响手表本地录音。
- [ ] 测试长时间分片发送的耗电、延迟、丢包和内存占用。

## F. 隐私与数据管理
- [ ] 用户可以删除记录和关联音频。
- [ ] 没有在客户端硬编码第三方服务密钥。
- [ ] 若使用云端 ASR，已明确告知音频上传、保存与删除方式。
- [ ] 隐私政策、麦克风和语音识别用途说明已完成。

## G. 构建报告
- [ ] Xcode 构建日志无错误。
- [ ] 在真实 iPhone + Apple Watch 上完成核心流程。
- [ ] 明确记录未通过项、设备型号、系统版本和复现步骤。

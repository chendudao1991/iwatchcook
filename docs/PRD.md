# 腕录 AI 产品需求文档（MVP）

## 1. 产品目标

开发 Apple Watch 与 iPhone 配套的原生录音转文字 App。手表负责快速录音与实时字幕展示，iPhone 负责完整音频管理、语音识别、文本编辑与导出。

## 2. 用户场景

- 会议、课堂、访谈和灵感记录。
- 不方便拿出手机时，用手表一键开始/停止录音。
- 实时模式下尽可能看到同步字幕。
- 网络中断时保留音频，稍后同步并完成录后转写。

## 3. 模式

### 实时模式
1. 用户在手表选择“实时”。
2. 手表创建本地录音文件，并同时采集音频。
3. 在手机可达时，手表发送 16 kHz、mono、Int16 PCM 音频分片。
4. iPhone 使用 Speech 框架生成临时转写，并把字幕回传手表。
5. 结束时关闭本地音频文件并加入 WatchConnectivity 文件传输队列。
6. iPhone 收到完整音频后，执行完整录后转写，用全文替代不完整的实时临时字幕。

### 录后模式
1. 用户在手表选择“录后”。
2. 手表独立录音并保存文件，不要求实时音频上传。
3. 结束后通过 `WCSession.transferFile` 同步文件。
4. iPhone 转写完整音频，显示状态、文字与原音频。

## 4. 功能范围

### P0：第一版必须完成
- Watch：开始/结束录音、显示时长、录音本地保存、录音状态和错误提示。
- Watch：实时/录后模式选择。
- iPhone：接收音频文件、录音列表、录音播放、全文转写、文本编辑与分享。
- 双端：连接状态、实时字幕（在连接与系统允许的条件下）、同步失败提示。
- 数据：本地持久化、音频与文本关联、删除录音及对应音频。

### P1：后续增强
- 暂停/恢复录音、录音标题重命名、分类标签。
- 更可靠的长音频断点转写、转写任务队列。
- iCloud 同步、TXT/Word/PDF 导出。
- 会议摘要、待办事项、专业术语词库。

### 暂不纳入 MVP
- 说话人自动分离。
- 服务端账号体系与订阅付费。
- 不受系统限制的后台实时字幕。
- 在 watchOS 端直接运行 iOS Speech 识别引擎。

## 5. 页面结构

### Apple Watch
- 首页：模式选择、开始录音、连接状态。
- 录音中：时长、实时字幕、结束并保存。
- 结束后：保存/同步提示。

### iPhone
- 录音列表：标题、日期、时长、状态、搜索。
- 录音详情：播放原音频、转写文字、编辑、保存、分享、重新转写。
- 实时状态：当前字幕与手机/手表连接提示。

## 6. 非功能需求

- 录音文件先本地保存，实时链路不得成为保存录音的前置条件。
- 录音与文字应关联同一 recording ID。
- 识别失败时保留原音频，并提供重试入口。
- 不应静默上传音频；云端处理需清晰告知用户并取得必要授权。
- 真机验证长时间录音、锁屏、弱网、来电、低电量、重复传输与 App 重启。
